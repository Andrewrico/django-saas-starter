Everything the first week needs

  • Sign-in that just works

    Email and password with verification and reset, plus Google and GitHub once you add keys.

  • Plans and limits

    Every user starts free. Limits live on the plan, so upgrades change one row, not your code.

  • Billing when you want it

    Stripe Checkout, customer portal and a signed webhook. Off until you switch it on.

  • A JSON API

    Session-authenticated, CSRF-protected and documented with OpenAPI and Swagger UI.

  • Backups built in

    SQLite with Litestream streams every change to Cloud Storage and restores on start.

  • Secure by default

    HTTPS, HSTS, CSP, rate-limited auth and a 90% test coverage gate in CI.
